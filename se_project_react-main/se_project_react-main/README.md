# WTWR

WTWR (What to Wear?) is a weather-aware clothing recommendation app that helps users choose outfits based on the current conditions. The experience combines live weather data with a simple, polished interface so users can see suggested garments and add their own items to the wardrobe.

## Overview

This implementation was built with React and Vite and includes:

- live weather data from the OpenWeather API
- weather-based clothing recommendations for different conditions
- reusable UI components for the main layout, cards, and modal dialogs
- a responsive experience for desktop and mobile screens

## Tech Stack

- React
- Vite
- JavaScript / JSX
- CSS
- OpenWeather API

## Features

- Displays the current weather and a matching visual card
- Recommends clothing items based on temperature and weather type
- Lets users add new clothing items through a modal form
- Shows item details in a dedicated preview modal

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local Vite URL shown in the terminal.
